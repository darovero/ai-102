# 🚀 Develop Generative AI Solutions in Azure

This lab series guides you through the essential steps to build, deploy, and optimize generative AI applications using Azure AI services.

---

## 🧪 Lab 01 – Prepare for an AI Development Project

Learn how to organize cloud resources in Azure AI Foundry projects so that developers are set up for success when building AI solutions.

---

## 🧠 Lab 02 – Choose and Deploy a Language Model

Generative AI applications are built on one or more language models. Learn how to find and select appropriate models for your generative AI project.

---

## 💬 Lab 03 – Create a Generative AI Chat App

Learn how to use the Azure AI Foundry SDK to build an app that connects to your project and chats with a language model.

---

## 🔁 Lab 04 – Use a Prompt Flow to Manage Conversation in a Chat App

Learn how to use prompt flows to manage conversational dialogs and ensure that prompts are constructed and orchestrated for best results.

---

## 📂 Lab 05 – Create a Generative AI App That Uses Your Own Data

Learn how to use the Retrieval Augmented Generation (RAG) model to build a chat app that grounds prompts using your own data.

---

## 🛠️ Lab 06 – Fine-Tune a Language Model

Learn how to use your own training data to fine-tune a model and customize its behavior.

---

## 🛡️ Lab 07 – Apply Content Filters to Prevent Harmful Output

Learn how to apply content filters that mitigate potentially offensive or harmful output in your generative AI app.

---

## 📊 Lab 08 – Evaluate Generative AI Model Performance

Learn how to evaluate models and prompts to optimize the performance of your chat app and its ability to respond appropriately.
