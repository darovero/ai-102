# AI-102 Certification Preparation Course

This repository contains structured materials for a course designed to help learners prepare for the **Microsoft Azure AI Engineer Associate (AI-102)** certification.

## 🎯 Purpose

The goal of this course is to provide both theoretical and practical guidance for individuals pursuing the **AI-102: Designing and Implementing an Azure AI Solution** certification. It is structured to support progressive learning of the key topics evaluated by Microsoft in the official exam.

## 📚 Repository Structure

- `presentations/`: Slide decks and visual materials used during sessions.
- `labs/`: Hands-on labs for implementing solutions using Azure AI services.
- `additional_info/`: Supplementary resources, links, articles, and relevant documentation.

## 📌 Based on Trusted Sources

This course is built upon:

- The official [Microsoft Learn documentation](https://learn.microsoft.com/en-us/certifications/azure-ai-engineer/)
- Examples and guides from the technical community promoting Azure AI services
- Contributions from certified professionals and collaborators who share and promote this knowledge

## 🧠 Target Audience

- Data engineers and developers interested in AI solutions
- Professionals working with Azure Cognitive Services, Azure Machine Learning, and Azure Bot Services
- Individuals aiming to earn the AI-102 certification as part of their professional development
